What it costs

Software target: CAD $0/month for the rules-only Google Apps Script version using the shop’s existing Workspace. No external AI or new shared-inbox subscription is required.

Human upkeep estimate: Connor 1–2 hours/month at the discovery estimate of CAD $65/hour, or CAD $65–$130/month in labour. “No new subscription” does not mean no staff cost.

What happens when it gets one wrong

Nothing is deleted or automatically answered. Sensitive and low-confidence messages go to Priya Review. Priya changes the Gmail label; the original decision and correction remain in the metadata audit. A failed run leaves the message eligible for retry. A missed urgent case disables urgent automation for review, while the shop returns to its existing manual process. The kill switch stops the timer without deleting email.
